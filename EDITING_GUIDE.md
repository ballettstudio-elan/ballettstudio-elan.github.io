# Как редактировать сайт (простая инструкция)

**Главное правило:** почти всё, что видно на сайте, лежит в папке **`src/data/`**. Компоненты и страницы трогать не нужно.

**Как не сломать:**
- Меняйте только текст **внутри кавычек** `'...'`.
- Не удаляйте кавычки, запятые в конце строк, скобки `{ }` и `[ ]`.
- Если в тексте нужен апостроф — пишите `’` (а не `'`), иначе строка оборвётся.
- После изменения смотрите результат: запустите `npm run dev` и откройте http://localhost:4321. Пока сайт запущен, изменения видны сразу после сохранения файла.
- Если после правки появилась ошибка — отмените последнее изменение (`Ctrl + Z`) и сохраните снова.

---

## 1. Запустить сайт у себя

```bash
npm install
```
(только первый раз)

```bash
npm run dev
```

Открыть: http://localhost:4321 · Остановить: `Ctrl + C`.

---

## 2. Добавить фотографию в галерею

1. Положите файл в папку **`public/images/galerie/`**.
   - Формат `.jpg`, ширина 1600–2000 пикселей (меньше вес — быстрее сайт).
   - Имя файла латиницей, без пробелов и ä/ö/ü: `sommerfest-2026.jpg`.
2. Откройте **`src/data/galerie.js`** и добавьте строку в список:
   ```js
   { datei: 'sommerfest-2026.jpg', alt: 'Kinder beim Sommerfest auf der Bühne' },
   ```
   `alt` — короткое описание фото на немецком (для незрячих и Google).
3. Сохраните — фото появится в галерее и откроется в увеличенном виде по клику.

**Удалить фото:** удалите его строку в `galerie.js`.
**Изменить порядок:** переставьте строки (первые 6 показываются и на главной странице).

⚠️ Фото детей — только с письменного согласия родителей.

## 3. Изменить тексты

| Что изменить | Файл |
|---|---|
| Главная страница (заголовок, кнопки, карточки преимуществ) | `src/data/studio.js` → `startseite` |
| Блок «Lust auf die erste Ballettstunde?» внизу страниц | `src/data/studio.js` → `aufruf` |
| Страница Über uns | `src/data/studio.js` → `ueberUns` |
| Меню сайта | `src/data/studio.js` → `navigation` |
| Название студии | `src/data/studio.js` → `studio.name` |
| Страница Unterricht | `src/data/unterricht.js` → `unterrichtSeite` |
| Фото на главном экране | `src/data/studio.js` → `hero.bild` |

Пример: чтобы изменить заголовок главной, найдите в `studio.js` строку
```js
titel: 'Tanzen mit Freude, Anmut und Leichtigkeit',
```
и поменяйте текст в кавычках.

## 4. Добавить или удалить блоки информации

**Карточка преимущества на главной** (`studio.js` → `vorteile.liste`):
```js
{ icon: 'stern', titel: 'Auftritte', text: 'Kurzer Text.' },
```
Иконки: `jahre`, `kind`, `lehrer`, `saal`, `gruppen`, `stern`. Удалить — удалите строку.

**Блок на странице Über uns** (`studio.js` → `ueberUns.bloecke`): скопируйте один блок `{ titel: ..., absaetze: [...], bild: ..., bildAlt: ... },` целиком и измените. Без фото — удалите строки `bild` и `bildAlt`. Абзац = одна строка в `absaetze`.

**Шаги «So einfach geht’s»** — `unterricht.js` → `ablauf`.

---

## 5. Преподаватели

Файл: **`src/data/lehrkraefte.js`**. Каждый преподаватель — один блок `{ ... },`.

- **Фото:** положите в `public/images/lehrkraefte/`, впишите `foto: '/images/lehrkraefte/имя.jpg'`. Без фото → `foto: ''` (покажутся инициалы).
- **Скрыть преподавателя** (не удаляя данные): `anzeigen: false`.
- **Показать второго преподавателя:** впишите `name`, `rolle`, при желании `foto` и `kurztext`, поставьте `anzeigen: true`.

**Блоки «Ausbildung», «Erfahrung» и т. п.** — список `abschnitte`:
```js
abschnitte: [
  { titel: 'Ausbildung', text: 'Staatliche Ballettschule …' },
  { titel: 'Erfahrung',  text: 'Seit 2005 Ballettlehrerin …' },
],
```
- **Удалить «Ausbildung»:** удалите эту одну строку.
- **Временно отключить:** поставьте `//` в начале строки.
- **Добавить:** уберите `//` у строки-примера или скопируйте строку.

Пишите только настоящие сведения.

## 6. Контактные данные

Файл: **`src/data/kontakt.js`** — единственное место. Данные автоматически появятся на странице Kontakt, в подвале и в Impressum.

```js
telefon: '0123 456789',        // как видит посетитель
telefonLink: '+49123456789',   // для звонка со смартфона: только + и цифры
email: 'info@beispiel.de',
strasse: 'Musterstraße 1',
plzOrt: '12345 Musterstadt',
```
Пустые кавычки `''` = пункт не показывается.

## 7. Возрастные группы, расписание, типы занятий

Файл: **`src/data/unterricht.js`**.

**Группы** (`altersgruppen`):
```js
export const altersgruppen = [
  { name: 'Minis',    alter: '4–5 Jahre', text: 'Spielerischer Einstieg.' },
  { name: 'Kids',     alter: '6–8 Jahre', text: '…' },
];
```
Как только список не пустой — группы появятся на странице Unterricht **и** в форме записи (выбор группы).

**Расписание** (`stundenplan`):
```js
export const stundenplan = [
  { tag: 'Montag', zeit: '16:00–17:00', gruppe: 'Minis' },
];
```
**Фраза о ценах** — `preiseHinweis`.

**Типы заявок** (`anfrageTypen`): можно менять подписи `label` и `text`. Поле `value` **не менять** — оно связано с базой данных. Новый тип заявки требует изменения в SQL (`supabase/migrations`) — попросите помощи.

## 8. Impressum и Datenschutz

Файл: **`src/data/rechtliches.js`**. Пустые поля видны на сайте жёлтой пометкой `[BITTE ERGÄNZEN]`. Когда всё заполнено и проверено — поставьте `entwurf: false` (уберёт жёлтый баннер «Entwurf»). Список вопросов — `LEGAL_CHECKLIST.md`.

## 9. Цвета и шрифты

Файл `src/styles/global.css`, блок `:root` в самом начале: например `--ink` — основной тёмно-синий, `--blush` — нежно-розовый фон.

## 10. Админ-панель (для мамы)

Адрес: `ваш-сайт.de/admin/`

- **Войти:** почта и пароль.
- Новые заявки отмечены розовой полосой, вверху счётчик «N neue». Новые появляются сами (без перезагрузки), всплывает сообщение.
- **Нажать на заявку** → подробности, кнопки:
  - **✓ Bestätigen** — занятие подтверждено (сообщите это человеку сами по телефону/почте!)
  - **✕ Ablehnen** — отклонено
  - **In Bearbeitung** — в работе
  - **Abgeschlossen** — всё сделано
- **Фильтр** по статусу — кнопки над списком; **поиск** — по имени, почте, телефону, номеру.
- **Удалить** — внизу окна заявки, с повторным подтверждением.
- Телефон и почта в заявке — кликабельные (позвонить / написать).

Важно: сайт **не отправляет** посетителю письмо о подтверждении. Подтверждение мама сообщает сама.
