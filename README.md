# BalletStudio „Elan“ — сайт с онлайн-записью

Сайт балетной студии на немецком языке: информационные страницы, форма записи, база данных заявок (Supabase) и защищённая админ-панель `/admin/`.

**Технологии:** [Astro](https://astro.build) (собирает обычные HTML-страницы — быстро и просто), Supabase (база данных + вход для администратора). Шрифты хранятся в проекте, никаких Google-сервисов, аналитики и cookies на публичной части.

---

## 1. Запуск на своём компьютере

Нужен Node.js (уже установлен). В папке проекта:

```bash
npm install
```

```bash
npm run dev
```

Откройте в браузере: http://localhost:4321  
Остановить: `Ctrl + C` в терминале.

Без настроенного Supabase сайт работает полностью, но форма честно пишет «Online-Anfrage nicht verfügbar», а админка — что база не настроена.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run build` | Собирает готовый сайт в папку `dist/` |
| `npm run preview` | Показывает собранный сайт из `dist/` |
| `npm run test:db` | Проверяет базу данных и защиту (36 проверок, без интернета) |

## 2. Настройка Supabase (один раз, ~15 минут)

1. Зайдите на https://supabase.com → **Sign up** (бесплатный тариф подходит).
2. **New project**:
   - Name: `ballettstudio-elan`
   - Database Password: придумайте надёжный и сохраните у себя (в проект его вписывать **не нужно**)
   - **Region: Central EU (Frankfurt)** — данные остаются в ЕС (важно для Datenschutz)
3. Подождите, пока проект создастся (1–2 минуты).
4. Слева **SQL Editor** → **New query** → откройте файл `supabase/migrations/001_anfragen.sql`, скопируйте **весь** текст, вставьте → **Run**. Должно быть «Success».
5. **Запретите регистрацию посторонних:** Authentication → Sign In / Providers (или *Settings*) → выключите **Allow new users to sign up**. Провайдер **Email** оставьте включённым.
6. Ключи для сайта: кнопка **Connect** вверху (или Project Settings → API). Нужны два значения:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon public** или **publishable** key
7. В папке проекта скопируйте файл `.env.example` → переименуйте копию в `.env` → впишите эти два значения.
8. Перезапустите `npm run dev`.

> ⚠️ **Никогда** не вписывайте в `.env` и никуда в проект ключ `service_role` / `secret`. Он не нужен этому сайту. Не присылайте ключи в чат.

### Создать учётную запись мамы (администратор)

1. Supabase → **Authentication → Users → Add user → Create new user**
   - Email: почта мамы
   - Password: надёжный пароль (сообщите его маме лично)
   - галочка **Auto Confirm User** — включить
2. **SQL Editor → New query** → вставьте текст из `supabase/admin_hinzufuegen.sql`, замените `MAMA@BEISPIEL.DE` на почту мамы → **Run**. Внизу появится строка с её почтой — готово.
3. Откройте `http://localhost:4321/admin/` и войдите.

Пароль нигде в коде не хранится. Сменить пароль: Authentication → Users → пользователь → «…» → Send password recovery / или удалите и создайте заново (и снова шаг 2).

### Проверка после настройки (сделайте сами 1 раз)

1. Отправьте заявку на `/probestunde/` → должна появиться «Vielen Dank» с номером `EL-…`.
2. В Supabase → Table Editor → `anfragen` — заявка видна.
3. В `/admin/` заявка появилась (без перезагрузки, точка «Live» зелёная).
4. Нажмите «Bestätigen» → перезагрузите страницу → статус сохранился.
5. Откройте `/admin/` в окне инкогнито **без входа** — заявок не видно.

## 3. Как устроена защита

- Посетитель может **только** вызвать функцию `anfrage_senden`: она проверяет поля, спам (скрытое поле-ловушка, слишком быстрое заполнение, не больше 3 заявок с одних контактов за 10 минут) и сохраняет заявку.
- Прочитать, изменить или удалить заявки посетитель не может — это запрещено самой базой (RLS), а не кнопками.
- Админ — только тот, чей аккаунт записан в таблицу `admins`. Админ может менять **только статус** и удалять заявки.
- Повторное нажатие «Senden» не создаёт дубликат.
- Сообщение «Vielen Dank» появляется только после того, как база вернула номер сохранённой заявки.

## 4. Публикация сайта в интернете

Сайт — это обычные файлы (папка `dist/`), его можно разместить на любом хостинге статических сайтов. Самый простой вариант — **Netlify** (или Cloudflare Pages, процесс похожий):

1. Загрузите проект на GitHub (файл `.env` туда **не попадёт** — он в `.gitignore`).
2. Netlify → **Add new site → Import from Git** → выберите репозиторий.
3. Build command: `npm run build` · Publish directory: `dist`
4. **Site settings → Environment variables** → добавьте `PUBLIC_SUPABASE_URL` и `PUBLIC_SUPABASE_ANON_KEY` (те же значения, что в `.env`).
5. Deploy. Затем подключите свой домен (Domain settings).
6. В `astro.config.mjs` замените `site: 'https://example.com'` на ваш домен.
7. Supabase → Authentication → URL Configuration → **Site URL** = адрес вашего сайта.
8. Перед публикацией пройдите `LEGAL_CHECKLIST.md`.

Выбор хостинга влияет на текст Datenschutzerklärung (кто хостинг-провайдер, где серверы) — впишите его в `src/data/rechtliches.js`.

## 5. Уведомления на e-mail (пока НЕ подключены)

Сейчас мама видит новые заявки **только в админ-панели** (счётчик, всплывающее сообщение, число во вкладке браузера). Письма на почту **не отправляются**.

Как подключить позже (нужен почтовый сервис, например Resend или Brevo, и их договор об обработке данных):
1. Supabase → Edge Functions → создать функцию, которая отправляет письмо через API почтового сервиса (ключ API хранить в Supabase → Edge Functions → Secrets, не в коде сайта).
2. Supabase → Database → Webhooks → на событие `INSERT` таблицы `anfragen` вызывать эту функцию.
3. В письмо лучше не вкладывать все данные заявки — достаточно «Neue Anfrage eingegangen» и ссылки на `/admin/`.
4. Дополнить Datenschutzerklärung.

## 6. Структура проекта

```
src/data/          ← ТЕКСТЫ И ДАННЫЕ (здесь редактировать)
  studio.js          тексты главной, Über uns, меню
  kontakt.js         телефон, e-mail, адрес
  lehrkraefte.js     преподаватели
  galerie.js         список фото галереи
  unterricht.js      группы, расписание, типы заявок, статусы
  rechtliches.js     данные для Impressum и Datenschutz
src/pages/         ← страницы (каждый файл = одна страница сайта)
  admin/index.astro  админ-панель
src/components/    ← повторяющиеся блоки (шапка, подвал, форма, галерея…)
src/admin/         ← логика и дизайн админ-панели
src/lib/           ← подключение к Supabase, тексты ошибок
src/styles/global.css  ← цвета, шрифты, дизайн
public/images/     ← фотографии
supabase/          ← SQL для базы данных
tests/             ← проверка базы данных
```
